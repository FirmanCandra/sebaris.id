# Keputusan desain Fase 1

- Palet memakai neutral sebagai permukaan, sage sebagai konteks, dan lime hanya untuk aksi utama agar fokus kerja admin tetap jelas.
- Inter dipakai untuk keterbacaan tabel dan formulir sambil tetap selaras dengan karakter logotype sebaris.id.
- Layout memusatkan daftar data dan formulir pada keputusan utama setiap halaman, bukan dashboard dengan metrik buatan.
- Navigasi berubah dari tab horizontal ke daftar vertikal di layar sempit agar target sentuh tetap nyaman.
- Motion dibatasi pada umpan balik hover dan focus agar pekerjaan administrasi tidak terganggu.
